# Voice prompts

Put voice clips (.mp3 or .m4a) here and list their file names in list.json.
Name each clip after the moment it plays:

- tier-bronze, tier-iron, tier-steel, tier-silver, tier-gold, tier-platinum, tier-obsidian (gear tiers)
- level-up (any level-up)
- streak-7, streak-15, streak-22, streak-30 (streak milestones)

Example list.json: ["tier-steel.mp3", "level-up.mp3"]
Only one sound plays at a time, and voice cheers for sets live in audio/cheers.
